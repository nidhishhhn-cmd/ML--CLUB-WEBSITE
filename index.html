Curriculum & Roadmaps

Engineered to take you from scratch to production.

Hands-on tracks, open-source projects, and research sessions designed for every skill level.

Module 01
Foundations of AI & Python
Master linear algebra, vector calculus, statistical inference, NumPy, and Pandas to manipulate high-dimensional data arrays with speed.
NumPy Pandas Linear Algebra Statistics
Module 02
Classical Machine Learning
Supervised and unsupervised algorithms, feature engineering, gradient boosting with XGBoost/LightGBM, and rigorous cross-validation pipelines.
Scikit-Learn XGBoost Regression Ensembles
Module 03
Deep Learning with PyTorch
Neural network internals, custom autograd engines, convolutional neural networks (CNNs), sequence models, and GPU-accelerated training.
PyTorch CNNs Backprop CUDA
Module 04
LLMs, Transformers & GenAI
Self-attention mechanisms, Hugging Face transformers, fine-tuning techniques (LoRA/QLoRA), Retrieval-Augmented Generation (RAG), and agent systems.
Transformers HuggingFace RAG LoRA
Module 05
Computer Vision & Multimodal
Real-time object detection (YOLOv8/v11), semantic segmentation, OpenCV pipelines, and vision-language models (VLMs) for edge applications.
OpenCV YOLO Segmentation VLMs
Module 06
MLOps & Model Deployment
Containerization with Docker, high-throughput model serving with FastAPI and ONNX Runtime, model monitoring, and automated CI/CD pipelines.
Docker FastAPI ONNX CI/CD
